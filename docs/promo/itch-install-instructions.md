<p><strong>macOS</strong></p>
<ol>
<li>Download the <code>.dmg</code> and open it.</li>
<li>Drag <strong>Dispatch HQ</strong> into your Applications folder.</li>
<li>Launch it from Applications (or Spotlight). The first time, right-click → <strong>Open</strong> to bypass Gatekeeper's unknown-developer warning.</li>
</ol>

<p><strong>Windows</strong></p>
<ol>
<li>Download the <code>.exe</code> installer and run it.</li>
<li>If SmartScreen warns about an unknown publisher, click <strong>More info → Run anyway</strong>.</li>
<li>Launch Dispatch HQ from the Start menu or desktop shortcut.</li>
</ol>

<p><strong>Linux</strong></p>
<ol>
<li>Download the <code>.AppImage</code>.</li>
<li>Right-click → <strong>Properties → Permissions</strong>, tick <strong>Allow executing file as program</strong> (or run <code>chmod +x DispatchHQ-*.AppImage</code>).</li>
<li>Double-click to run — no install required.</li>
</ol>

<p>All platforms: the app loads the live game, so you'll always be on the latest version — no re-downloading for updates. An internet connection is required to play.</p>
