## Audit — phone (<768px) and tablet (768–1023px) navigation inventory

### Surfaces that exist today

| Surface | Phones | Tablets (md–lg) | Desktop (lg+) |
|---|---|---|---|
| TopBar tab strip (`TopBar.tsx`) | hidden (`hidden md:flex`) | ✅ icons only (labels `hidden lg:inline`) | ✅ icons + labels |
| Bottom nav (`MobileNav.tsx`) | ✅ 4 tabs + Dispatch button | hidden (`md:hidden`) | hidden |

### Findings

1. **Depth gap on phones — Leaderboard & Public Chat are 2 taps away.**
   Desktop reaches them in the top tab strip (1 tap). Phones get 4 bottom tabs
   (Calls/Stations/Units/Crew) + the Dispatch button; Leaderboard and Chat are
   only behind the hamburger → sidebar. The phone's *primary* nav has no path.
   **→ Fix: bottom-nav "More" sheet** with Leaderboard, Public Chat,
   Notifications, Pause, Log Out — every destination 1 tap on phones.

2. **iOS double-tap zoom / 300 ms delay on interactive chrome.**
   The viewport meta is `width=device-width, initial-scale=1.0, viewport-fit=cover`
   with no `user-scalable=no` (good — keep pinch-zoom). But no
   `touch-action: manipulation` anywhere, so rapid taps on nav buttons can
   trigger double-tap zoom re-layout on iOS Safari.
   **→ Fix: global `touch-action: manipulation` on interactive elements.**

3. **Tablet tab strip is icon-only with no tooltips.**
   At md–lg the strip renders icons with labels `hidden lg:inline` — 6 cryptic
   glyphs (some are emoji). No `title` fallback.
   **→ Fix: `title={item.label}` on each tab button.**

4. **Slide-over panels sit flush to the bottom edge on notched phones.**
   Stations/Employees panels and the notification panel are
   `fixed top-12 … bottom-0` at z-60/z-65 — they cover the bottom nav, so the
   home-indicator area overlaps the last scroll row (only `p-3`/`p-2` padding).
   **→ Fix: `pb-[calc(p+env(safe-area-inset-bottom))]` on scroll containers.**

5. **Good already (no change):** root uses `100dvh` (App.tsx) so the iOS URL-bar
   never cuts the HUD; bottom nav already honors `env(safe-area-inset-bottom)`;
   modals cap at `max-h-[85vh]`-ish and center on small screens; panels have
   explicit close (✕) buttons; the Dispatch Center goes full-width on phones;
   reduced-motion + focus-visible rules exist.

### Leftovers (not in this release)
- On-screen *layout* verification at true 375 px / 1920 px (preview pane is
  fixed-width; needs a real device pass — see `preview-and-scan.md`).
- ✅ **Done in v0.29.1:** tablet strip shows labels at `md+` with tighter
  padding — measured to fit at 768/900/1024/1280/1440 (Puppeteer; no
  overflow, no scroll). Compact desktops (1024–1279 px) moved the system
  toggles into the ⋯ menu so the labeled strip fits; full chrome returns at
  `xl` (1280 px+).
- Bottom sheet lacks a `Report a Bug` entry (owned by TopBar state; wire when
  the sheet grows).

## Tasks

1. **MobileNav More sheet** — 5th column (⋯) opens an animated bottom sheet:
   Leaderboard, Public Chat, Notifications, Pause, Log Out (danger). Wired via
   new optional props `onOpenNotifications`, `onPause`, `onLogout`; closes on
   any selection, backdrop tap, or tab change.
2. **Touch chrome** — `touch-action: manipulation` for `button`, `[role=button]`,
   `a`, `input`, `select`, `textarea` in `index.css`.
3. **Tablet tooltips** — `title` on top-nav tab buttons.
4. **Safe-area bottoms** — Stations panel, Employees panel, notification panel
   scroll containers gain `pb-[calc(…+env(safe-area-inset-bottom))]`.
5. **Release** — bump `0.29.0` (both server entrypoints), release note, verify
   (web tsc + tests, build), deploy to Zo.
