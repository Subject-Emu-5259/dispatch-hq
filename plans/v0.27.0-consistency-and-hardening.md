### 2. Global JSON body-size cap (server)

**Files:** `servers/game-server/src/lib/bodyLimit.ts` (new) +
`bodyLimit.test.ts` (new), `serve-combined.ts`, `index.ts`

No route bounded its body, so `c.req.json()` parsed a client's bytes straight
into memory. A path-aware wrapper over Hono's `bodyLimit` 413s oversized
payloads before any handler runs: **1 MiB** default, **10 MiB** for
`/api/player/saves` (a save carries the whole game state). Four unit tests
cover under/over the cap, the save override, and `limitForPath`.

### 3. Per-player write-route throttling (server)

**Files:** `servers/game-server/src/lib/rateLimit.ts`, `serve-combined.ts`,
`index.ts`

The remaining authenticated DB writes had no throttle. Each now gets a
per-account bucket via the v0.26.0 `keyFn` (`playerKey`), tuned per cadence:
`player/stats` 60/min, `analytics/session` 30/min, `missions` 60/min,
`settings` 30/min, `social` 30/min, `inbox` 60/min, `alliances/chat` 30/min,
`alliances/xp` 60/min. Dev entrypoint (`index.ts`) mirrors the routes it mounts
(no alliance routes there).

### 4. Chemical-spill chain mission (content)

**Files:** `packages/shared/src/constants/missions.ts`,
`chainMissions.test.ts`

New `chemical_chain` ("Chemical Spill Response"):
**fuel_spill (fire) → hazmat_medical (ems) → factory_fire (fire)**. Reuses
existing templates, so credits/XP stay band-safe. A dedicated test pins the
stage sequence, services, and `nextStage` behavior.

### 5. BALANCE.md truth pass (docs)

**Files:** `docs/BALANCE.md`

Rewrote the stale v0.19.x analysis: records F1 (credits) as resolved in
v0.22.0, F2 (tier monotonicity) as resolved under the per-service model, F3
(XP) as resolved here, F4 (the `garage_fire > room_fire` contradiction) as
moot, and F5 (payout stack) as still informational. Includes current
per-service credit/XP median tables and a note that all v0.25/v0.26 templates
pass the band audits.
