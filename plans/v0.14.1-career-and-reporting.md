# v0.14.1 — Career & Reporting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Give players a career identity (rank ladder), a shareable end-of-shift debrief, credit for answering Mutual Aid requests, and push notifications for critical calls.

**Architecture:** Ranks are a pure mapping in shared (`rankForLevel(level, service)`). The debrief extends the existing `ShiftReportModal` with an End Shift flow that aggregates already-tracked shift stats + per-unit counts. Mutual-aid credit adds a `mutualAidAnswered` career stat (store + server schema column + leaderboard sort key). Push notifications use the Web Notification API gated by a `pushEnabled` setting, with the PWA service worker.

**Tech Stack:** TypeScript, Zustand, Hono + Drizzle (server), Web Notification API, Tailwind CSS.

## Global Constraints

- Career stats live in `apps/web/src/stores/gameStore.ts` (`CareerStats`) and sync via `apps/web/src/lib/apiClient.ts` `syncCareerStats()`.
- Leaderboard route: `servers/game-server/src/routes/leaderboard.ts`; schema: `servers/game-server/src/db/schema.ts` (Drizzle + Postgres).
- Shift stats already tracked in the store's `shift` object (missionsCompleted, creditsEarned, zoneStats, etc.).
- UI: dark-first Tailwind, lucide-react.
- Validation: shared/web/server typechecks, `pnpm build`, vitest.

```ts
import type { ServiceType } from '../types/unit';

export interface Rank {
  id: string;
  minLevel: number;
  title: string;
  serviceTitles: Partial<Record<ServiceType, string>>;
  rewardBonus: number;
  icon: string;
}

export const RANKS: Rank[] = [
  { id: 'rookie',        minLevel: 1,  title: 'Rookie',        serviceTitles: { police: 'Rookie Officer', fire: 'Probationary Firefighter', ems: 'Probationary EMT' }, rewardBonus: 1.0,  icon: '🌱' },
  { id: 'officer',       minLevel: 3,  title: 'Officer',       serviceTitles: { police: 'Police Officer',  fire: 'Firefighter',            ems: 'EMT' },              rewardBonus: 1.05, icon: '🚔' },
  { id: 'sergeant',      minLevel: 6,  title: 'Sergeant',      serviceTitles: { police: 'Sergeant',       fire: 'Engine Lieutenant',      ems: 'Paramedic' },        rewardBonus: 1.1,  icon: '🎖️' },
  { id: 'lieutenant',    minLevel: 9,  title: 'Lieutenant',    serviceTitles: { police: 'Lieutenant',     fire: 'Battalion Chief',       ems: 'Field Supervisor' }, rewardBonus: 1.15, icon: '⭐' },
  { id: 'captain',       minLevel: 12, title: 'Captain',       serviceTitles: { police: 'Captain',        fire: 'Assistant Chief',       ems: 'Operations Manager' }, rewardBonus: 1.2, icon: '🎖️' },
  { id: 'chief',         minLevel: 15, title: 'Chief',         serviceTitles: { police: 'Police Chief',   fire: 'Fire Chief',            ems: 'EMS Director' },     rewardBonus: 1.3,  icon: '👑' },
];

export function rankForLevel(level: number, service?: ServiceType): Rank {
  let best = RANKS[0];
  for (const r of RANKS) if (level >= r.minLevel) best = r;
  if (service && best.serviceTitles[service]) return { ...best, title: best.serviceTitles[service]! };
  return best;
}

export function nextRank(level: number): Rank | null {
  return RANKS.find((r) => r.minLevel > level) ?? null;
}
```

```ts
import { loadSettings } from './settings';

export async function ensureNotificationPermission(): Promise<boolean> {
  if (!('Notification' in window)) return false;
  if (Notification.permission === 'granted') return true;
  if (Notification.permission === 'denied') return false;
  const res = await Notification.requestPermission();
  return res === 'granted';
}

export function notify(title: string, body: string, icon = '🚨'): void {
  if (document.visibilityState !== 'hidden') return;
  if (!loadSettings().pushEnabled) return;
  if (!('Notification' in window) || Notification.permission !== 'granted') return;
  new Notification(title, { body, icon: 'icon-192.png' });
}
```
