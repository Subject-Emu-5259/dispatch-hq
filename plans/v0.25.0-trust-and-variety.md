## Tasks

### 1. Rate-limit `/api/auth/guest` (server)

**Files:** `servers/game-server/src/serve-combined.ts`

`/api/auth/guest` mints accounts with zero throttling — the only unthrottled
account-minting endpoint. Added `rateLimit({ windowMs: 60_000, max: 10 })`
matching register/login. 429s carry `Retry-After`.

### 2. Server-side auth input validation (server)

**Files:** `servers/game-server/src/lib/validation.ts` (new),
`servers/game-server/src/lib/validation.test.ts` (new),
`servers/game-server/src/routes/auth.ts`

New pure validators, wired into register/login:

- `isValidEmail` — RFC-5322-lite; rejects junk (`""`, `not-an-email`, `a@b`,
  `x@y.z` single-char TLD) and anything over varchar(255). Accepts `+tags`,
  subdomains, 2+ letter TLDs.
- `isValidUsername` — 3–30 chars after trim, `[A-Za-z0-9 _-]`, must start
  letter/digit; guest-style `Guest_<hex>` passes. Mirrors varchar(30).
- `isValidPassword` — ≥ 6 (route rule) and ≤ 128 so a multi-MB paste can't be
  scrypt-hashed (CPU blow-up) or rejected by Postgres later.
- `fieldTooLong` — generic varchar-cap guard for free-text fields.

Invalid input returns 400 with a message, not a Postgres "value too long" 500.

New credits chosen so every existing template stays inside its ±20% band and

### 4. Auth screen: real server errors + in-flight state (UI)

**Files:** `apps/web/src/lib/apiClient.ts`

AuthScreen already showed `err.message` and disabled buttons while submitting.
The missing piece: a 429's `Retry-After` header was ignored. `apiFetch` now
parses `Retry-After` and appends "Try again in ~Ns" to the thrown error, so the
user sees a real countdown instead of a bare "Too many requests".

### 5. Mission card keyboard operability + tier badge contrast (UI/a11y)

**Files:** `apps/web/src/components/MissionCard.tsx`,
`packages/shared/src/constants/missionTiers.ts`

- Sidebar `MissionCard` (a `motion.div` with only `onClick`) is now a proper
  toggle: `role="button"`, `tabIndex={0}`, `aria-expanded`, Enter/Space
  activation guarded by `e.target !== e.currentTarget` so nested controls
  (checkboxes, dispatch button) never double-fire. Focus ring comes from the
  global `:focus-visible` rule (same as every other control).
- Tier badge `chipClass` text brightened `-400` → `-300` (≥ 7:1 on the dark
  cards) and chip fill raised `/10` → `/15` so the pill reads as defined, not a
  ghost tint. One shared change fixes the badge in the sidebar card, dispatch
  board, and map popup.
