# v0.13.1 — Mission Depth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Give every mission a labeled difficulty tier, make missions chain into staged sequences, and let players tune spawn pacing — while enforcing the real spawn cap.

**Architecture:** Difficulty tiers are a pure mapping in `packages/shared` (testable, no UI). Chain missions add `chainId`/`chainStage` fields to `Mission`, a `CHAIN_DEFINITIONS` table in shared, and a `nextChainMission()` helper in the web app that spawns the next stage via the existing `buildMission()`. Spawn pacing moves from hardcoded constants in `App.tsx` into server-persisted `DispatchSettings`.

**Tech Stack:** TypeScript, Zustand (`gameStore`), Tailwind CSS, lucide-react, vitest, Web Audio.

## Global Constraints

- All mission construction goes through `apps/web/src/lib/spawn.ts` `buildMission()`.
- Shared types live in `packages/shared/src/types`, constants in `packages/shared/src/constants`.
- Settings persist via `apps/web/src/utils/settings.ts` (server-backed `player_settings`).
- UI: dark-first Tailwind, lucide-react icons.
- Validation: `pnpm --filter @dispatch-hq/shared exec vitest run`, `pnpm --filter @dispatch-hq/web exec tsc --noEmit`, `pnpm build`.

```ts
// packages/shared/src/constants/missionTiers.ts
export type DifficultyTier = 'routine' | 'moderate' | 'serious' | 'critical';

export const DIFFICULTY_TIER_ORDER: Record<DifficultyTier, number> = {
  routine: 0, moderate: 1, serious: 2, critical: 3,
};

export const TIER_META: Record<DifficultyTier, { label: string; color: string; chipClass: string; icon: string }> = {
  routine:  { label: 'Routine',  color: '#4ade80', chipClass: 'bg-green-500/10 text-green-400 border-green-500/30', icon: '🟢' },
  moderate: { label: 'Moderate', color: '#fbbf24', chipClass: 'bg-amber-500/10 text-amber-400 border-amber-500/30', icon: '🟡' },
  serious:  { label: 'Serious',  color: '#fb923c', chipClass: 'bg-orange-500/10 text-orange-400 border-orange-500/30', icon: '🟠' },
  critical: { label: 'Critical', color: '#f87171', chipClass: 'bg-red-500/10 text-red-400 border-red-500/30', icon: '🔴' },
};

export function difficultyTierFor(difficulty: number): DifficultyTier {
  if (difficulty <= 3) return 'routine';
  if (difficulty <= 5) return 'moderate';
  if (difficulty <= 8) return 'serious';
  return 'critical';
}

export function tierOf(m: { difficulty: number }): DifficultyTier {
  return difficultyTierFor(m.difficulty);
}
```

- [x] **Step 3: Write minimal implementation**

```ts
// apps/web/src/lib/missionChains.ts
import type { Mission, ServiceType } from '@dispatch-hq/shared';
import { chainForId, nextStage } from '@dispatch-hq/shared';
import type { CityData } from '@/stores/gameStore';
import { buildMission } from './spawn';

export function chainRewardBonus(m: Mission): number {
  return m.chainStage && m.chainStage >= 2 ? 1.25 : 1;
}

export async function spawnChainStage(
  completed: Mission,
  city: CityData | null,
  level: number,
  addMission: (m: Mission) => void,
): Promise<Mission | null> {
  if (!completed.chainId || !completed.chainStage) return null;
  const def = chainForId(completed.chainId);
  if (!def) return null;
  const stage = nextStage(def, completed.chainStage);
  if (!stage) return null;
  const mission = await buildMission(stage.service as ServiceType, city, {
    level,
    origin: completed.location,
    prefix: `${def.name}: `,
    template: def.stages.find((s) => s.templateId === stage.templateId) as any,
  });
  mission.chainId = def.id;
  mission.chainStage = (completed.chainStage ?? 0) + 1;
  mission.chainTotal = def.stages.length;
  addMission(mission);
  return mission;
}
```

Note: `buildMission`'s `template` option expects a `MissionTemplate` — chain stages store `templateId`; map templateId → the template object from `getMissionsForService(service).find(t => t.id === stage.templateId)` before passing (adjust Step 3 code to do that lookup; the test only asserts chain fields + addMission called).
