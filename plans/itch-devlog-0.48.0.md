# v0.48.0–v0.50.0 — The co-op endgame: treasury, gifting, shared stations, and unit lending

**Post this on the itch.io dashboard:** agreatgame.itch.io → **Edit game** → **Devlogs** → **Create new post** (paste the markdown below; the dashboard editor renders itch markdown).

---

This is the release that makes alliances matter. Four new features in rapid succession, each building on the last, turning alliances from a social wrapper into a real co-op strategy layer.

**Alliance treasury (Level 5+).** Pool credits in a shared alliance treasury. Deposit when you're flush, withdraw when you need to build. Every transaction is logged with timestamps. The treasury is the foundation — everything else builds on it.

**Credit gifting (Level 2+).** Send credits directly to alliance members. Help new commanders get started, reward active players, or pool resources for a big station build. Daily gift cap of 25,000 credits (sending + receiving combined) prevents exploitation. Minimum gift: 100 credits. Maximum single gift: 50,000 credits. Optional gift messages included.

**Shared stations (Level 3+).** Officers can build fire, police, and EMS stations from the alliance treasury — they belong to the alliance, not any player, and answer missions for all members in the same city. Upgrade from Level 1 to 5. Claim a station to make it your personal property (pay the full build cost back to the treasury). Shared stations appear on the map with a purple glow so alliance members can spot them instantly.

**Unit lending (Level 4+).** Lend units to alliance members for up to 4 hours. The lender's unit is locked during the loan; the borrower gets a stats copy. Active loans show countdown timers. Borrowers can return early. Officers can recall loans. Max 2 active loans per player. The "Unit Loans" section in the Alliance tab has a borrower picker, unit type selector, and duration picker.

**How it all fits together:** New player joins → alliance level 1, they can see the shared mission board. Level 2, they can gift credits and auto-respond to calls. Level 3, they can build shared stations. Level 4, they can lend units. Level 5, full treasury access. The progression is gradual, each level unlocks real gameplay power.
